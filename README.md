# The Legend of Anantam — Starter Project

This is the actual editable website project based on the vision described in the conversation.

## Run it
1. Extract the ZIP.
2. Open `Anantam_Legend_Project/index.html` in a modern browser.
3. The story starts automatically. Use **Pause story** or **Skip ahead** if you want control. Turn narration on with the top-right button (browser speech synthesis required).

## Included in this starter
- Navya stays on the left while the story appears on the right.
- Navya's supplied appearance is included as `assets/navya-reference.jpeg`.
- Automatic timed story scenes introduce Anantam, Navya, Vritra, Nandhan, and the Lotus/Diamond/Key quest.
- The Navya portrait changes to an expression asset for the Nandhan and Vritra scenes.
- Pointer movement animates small eye overlays as a **prototype approximation**.
- A small hidden rune reveals an Easter-egg message when hovered over.
- Responsive layout for narrower screens.

## Important current limitations
This is a working website starter, not a completed 3D game. The supplied Navya image is a 2D image. Eye tracking is approximated with overlays; genuine 3D body movement, accurate eye rigging, facial animation, and lip-sync require a rigged 3D model and animation assets. The story advances automatically, but the secret is currently discovered by hovering over the rune.

## Files
- `index.html`: page structure
- `style.css`: visual design and responsive layout
- `script.js`: scene timing, character reactions, eye-pointer prototype, narration, Easter egg
- `assets/`: Navya reference and available character images

No build tools or package installation are required for this starter. Internet access is used only for optional Google Fonts; browser speech narration is optional.
